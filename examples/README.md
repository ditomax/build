# build — example results

These files are fictitious examples (Example GmbH, feature `OFA`, "Offer draft assistant"). They show what finished result files look like. They are not templates; the templates are in `../templates/`.

- `10-intake.md` — written by the intake stage (`build-intake`): extraction from the maquette brief and prototype, then grilling.
- `10-intake-path-r.md` — a second case (Example GmbH, feature `SRA`, "Service report assistant", test run-04): intake on path `mixed+R` from an H2/3 brief built on an idea register — Register trace with one row per R-ID (including the maquette's own `R-M<n>` items) and the coverage close; Operation, Running cost and Load and growth prefilled from the register.
- `20-concept.md` — written by the concept stage (`build-concept`): numbered requirements, ADR links, interactions, architecture in slices, consistency review.

Not shown: synthesis (`30-synthesis.md` plus the product code) and rescue (`40-rescue.md`), and the shared files `CONTEXT.md` and `decisions/` that the examples refer to.
Every real result file has the same frontmatter and the same headings as these examples, in the same order.
