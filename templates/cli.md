# Development CLI

_The project's dev CLI `tools/dev.py` — the single execution surface for development, testing and configuration (RULES §15). It is a development tool, not part of the product: a CLI for users or operators is a product feature with its own requirements (concept question C9). The block between the markers is generated by `python tools/dev.py docs`; `python tools/dev.py check` fails while it is out of date. Do not edit inside the markers._

## Purpose and rules

- Agents run tests, checks and configuration through this CLI — not through ad-hoc commands — and register any new command in `agent-testing.md`.
- Secrets appear by name only; values of keys marked secret are masked (RULES §10.6).
- Adding a command: code first, then `python tools/dev.py docs`, both in one commit.
